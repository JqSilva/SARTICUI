\doxysubsection{Detailed Description}
\doxylink{namespace_code_igniter}{Code\+Igniter} Encryption Manager

Provides two-\/way keyed encryption via PHP\textquotesingle{}s Sodium and/or Open\+SSL extensions. This class determines the driver, cipher, and mode to use, and then initializes the appropriate encryption handler.
