\doxysubsection{Detailed Description}
Class Cell

A simple class that can call any other class that can be loaded, and echo out it\textquotesingle{}s result. Intended for displaying small blocks of content within views that can be managed by other libraries and not require they are loaded within controller.

Used with the helper function, it\textquotesingle{}s use will look like\+: \begin{DoxyVerb}    viewCell('\Some\Class::method', 'limit=5 sort=asc', 60, 'cache-name');
\end{DoxyVerb}


Parameters are matched up with the callback method\textquotesingle{}s arguments of the same name\+: \begin{DoxyVerb}    class Class {
        function method($limit, $sort)
    }
\end{DoxyVerb}


Alternatively, the params will be passed into the callback method as a simple array if matching params are not found. \begin{DoxyVerb}    class Class {
        function method(array $params=null)
    }
\end{DoxyVerb}
