\doxysubsection{Detailed Description}
Set of static methods useful for CLI request handling.

Portions of this code were initially from the Fuel\+PHP Framework, version 1.\+7.\+x, and used here under the MIT license they were originally made available under. Reference\+: \href{http://fuelphp.com}{\texttt{ http\+://fuelphp.\+com}}

Some of the code in this class is Windows-\/specific, and not possible to test using travis-\/ci. It has been phpunit-\/annotated to prevent messing up code coverage.
