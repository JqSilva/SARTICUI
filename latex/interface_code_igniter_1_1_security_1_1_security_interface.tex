Sanitize Filename

Tries to sanitize filenames in order to prevent directory traversal attempts and other security threats, which is particularly useful for files that were supplied via user input.

If it is acceptable for the user input to include relative paths, e.\+g. file/in/some/approved/folder.\+txt, you can set the second optional parameter, \$relative\+Path to TRUE.
