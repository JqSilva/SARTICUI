\doxysubsection{Detailed Description}
Services Configuration file.

Services are simply other classes/libraries that the system uses to do its job. This is used by \doxylink{namespace_code_igniter}{Code\+Igniter} to allow the core of the framework to be swapped out easily without affecting the usage within the rest of your application.

This is used in place of a Dependency Injection container primarily due to its simplicity, which allows a better long-\/term maintenance of the applications built on top of \doxylink{namespace_code_igniter}{Code\+Igniter}. A bonus side-\/effect is that IDEs are able to determine what class you are calling whereas with DI Containers there usually isn\textquotesingle{}t a way for them to do this.
