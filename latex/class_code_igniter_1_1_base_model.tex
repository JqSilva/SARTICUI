The Base\+Model class provides a number of convenient features that makes working with a databases less painful. Extending this class provide means of implementing various database systems

It will\+:
\begin{DoxyItemize}
\item simplifies pagination
\item allow specifying the return type (array, object, etc) with each call
\item automatically set and update timestamps
\item handle soft deletes
\item ensure validation is run against objects when saving items
\item process various callbacks
\item allow intermingling calls to the db connection
\end{DoxyItemize}
