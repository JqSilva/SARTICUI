\item Status code and reason phrase

\item Message body

A shortcut method that allows the developer to set all of the cache-\/control headers in one method call.

The options array is used to provide the cache-\/control directives for the header. It might look something like\+: \begin{DoxyVerb} $options = [
     'max-age'  => 300,
     's-maxage' => 900
     'etag'     => 'abcde',
 ];
\end{DoxyVerb}


Typical options are\+:
\begin{DoxyItemize}
\item etag
\item last-\/modified
\item max-\/age
\item s-\/maxage
\item private
\item public
\item must-\/revalidate
\item proxy-\/revalidate
\item no-\/transform
\end{DoxyItemize}
