\doxysubsection{Detailed Description}
Interface Route\+Collection\+Interface

A Route Collection\textquotesingle{}s sole job is to hold a series of routes. The required number of methods is kept very small on purpose, but implementors may add a number of additional methods to customize how the routes are defined.

The Route\+Collection provides the Router with the routes so that it can determine which controller should be run.
